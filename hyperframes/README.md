# HyperFrames Project

This folder is the root directory for all videos created with HyperFrames.

All HyperFrames-related files must stay inside this directory, including briefs,
scripts, prompts, source assets, generated clips, subtitles, renders, logs, and
final exports.

## Folder Rules

- `briefs/`: video briefs, product requirements, and delivery specs.
- `scripts/`: structured scripts, shot lists, and narration text.
- `prompts/`: image, video, voice, and editing prompts.
- `assets/input/`: original user-provided materials.
- `assets/images/`: generated or selected images.
- `assets/video/`: generated video clips and intermediate video assets.
- `assets/audio/`: voiceover files and sound effects.
- `assets/subtitles/`: subtitle files such as SRT or ASS.
- `assets/music/`: background music files.
- `assets/cover/`: cover images and thumbnails.
- `renders/`: intermediate renders and previews.
- `exports/`: final deliverables.
- `logs/`: generation logs, QA notes, and error logs.
- `metadata/`: task JSON, manifests, and platform publishing metadata.
- `tmp/`: temporary files that can be regenerated.
