# 04 Voiceover

## 配音要求

```text
语言：中文普通话
声音：女生
年龄感：20-30 岁
语气：自然、清晰、轻快、专业
情绪：鼓励感，不焦虑、不夸张
用途：知识类短视频旁白
```

## 语速

```text
整体时长：12 秒
语速：中快
停顿：每个信息点之间有轻微停顿
不要播得像广告叫卖
```

```text
在纽约读书找工作，别只靠手动改简历。

想更快做出求职内容？立即尝试用 AI 帮助你的求职。
```

## 分段时间

```text
0-3 秒：
在纽约读书找工作，别只靠手动改简历。
```
