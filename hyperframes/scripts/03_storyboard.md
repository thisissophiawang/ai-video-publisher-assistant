# 03 Storyboard

## 镜头 1：痛点钩子

时间：

```text
0-3 秒
```

画面：

```text
纽约市 skyline 作为开场背景，快速切到哥大校园或图书馆学习场景。
海外留学生坐在书桌前，电脑屏幕打开多个求职页面：
LinkedIn、英文简历、岗位 JD、邮箱。
画面节奏略快，表现信息很多、任务很碎。
```

字幕：

```text
纽约留学生找工作
别只靠手动改简历
```

旁白：

```text
在纽约读书找工作，别只靠手动改简历。
```

素材说明：

```text
参考图路径：
hyperframes/assets/input/reference_nyc_skyline.jpg
hyperframes/assets/input/reference_columbia_graduation.jpg

可以使用生成画面，不要使用真实个人隐私页面。
纽约 skyline 和哥大校园只作为背景氛围，不要出现真实学生身份信息。
```

时间：

```text
3-5 秒
```

画面：

```text
出现 LinkedIn 主页风格画面。
用户提供的参考图可以作为这一页的视觉参考或素材之一。
背景可叠加浅蓝色纽约城市轮廓或哥大校园细节，保持留学生场景连贯。
画面上突出：
建立完整 LinkedIn 主页
有效社交
提高竞争力
扩大人际圈
展现自我
```

字幕：

```text
AI 优化 LinkedIn
```

旁白：

```text
用 AI 优化 LinkedIn、
```

素材说明：

```text
参考图路径：
hyperframes/assets/input/reference_linkedin_style.jpg

该图只用于 LinkedIn 镜头，不作为整条视频唯一画面。
```

## 镜头 3：JD 分析 + 简历关键词

时间：

```text
5-8 秒
```

画面：

```text
AI 工具界面读取纽约岗位或美国岗位的英文 Job Description。
右侧显示提取出的岗位关键词，例如：
Data Analysis
SQL
Communication
Marketing
Strategy

下方出现英文简历被高亮优化的效果。
背景可以保留模糊的哥大图书馆、校园桌面或纽约窗景，突出“在纽约求职”的环境。
```

字幕：

```text
分析 JD / 优化关键词
```

旁白：

```text
分析 JD、生成 Cover Letter，
```

## 镜头 4：英文面试模拟

时间：

```text
8-10 秒
```

画面：

```text
学生在哥大校园附近的学习空间或宿舍里，面对电脑进行模拟面试。
屏幕上出现英文面试问题卡片：
Tell me about yourself.
Why this role?
What is your strength?

可加入纽约城市窗景、校园书桌、哥大蓝色元素，但不要出现未经授权的清晰校徽。
```

字幕：

```text
模拟英文面试
```

旁白：

```text
还能模拟英文面试。
```

## 镜头 5：结尾 CTA

时间：

```text
10-12 秒
```

画面：

```text
画面切到简洁的 AI 视频制作输入框。
输入框里出现一句话：
海外留学生怎么用 AI 提升求职效率

旁边出现生成按钮或进度动效。
背景使用纽约 skyline 或哥大校园的浅虚化画面，让 CTA 有明确留学生场景。
```

字幕：

```text
立即尝试
用 AI 帮助你的求职
```

旁白：

```text
想更快做出求职内容？立即尝试用 AI 帮助你的求职。
```

视觉重点：

```text
结尾 CTA 必须清晰，文字不能被平台 UI 遮挡。
```
