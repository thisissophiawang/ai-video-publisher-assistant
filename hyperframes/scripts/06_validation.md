# 06 Validation

## 基础规格验收

```text
文件格式：MP4
分辨率：720 x 1280
比例：9:16 vertical
时长：12 秒
允许误差：不超过 0.5 秒
帧率：30fps
```

## 内容验收

```text
主题必须明确：海外留学生如何用 AI 提升求职效率。
目标观众必须明确：其他正在求职的海外留学生。
视频不能只是 LinkedIn 截图动效。
视频必须有纽约市或哥大背景氛围。
视频不能只是纽约/哥大空镜，必须展示 AI 求职提效流程。
必须包含至少 4 类求职提效场景：
LinkedIn 优化
JD 分析
Cover Letter
英文面试模拟
结尾必须出现“立即尝试用 AI 帮助你的求职”。
```

## 视觉验收

```text
整体风格要接近参考图：纽约城市感、哥大校园感、浅蓝、干净、大字、清单感。
纽约 skyline 参考图可作为开场、转场或结尾背景。
哥大毕业/校园参考图可作为身份锚点。
LinkedIn 参考图只能作为其中一页素材。
镜头之间必须有内容变化。
字幕必须清晰可读。
重要文字不得被平台 UI 遮挡。
画面不得出现明显错位、裁切、重叠或黑边。
```

## 配音验收

```text
必须是中文女生声音。
语气自然、清晰、轻快、专业。
旁白内容必须与 04_voiceover.md 一致。
英文词 LinkedIn、JD、Cover Letter 发音不能明显错误。
背景音乐不能盖过人声。
```

## 字幕验收

```text
字幕语言为中文。
每屏字幕不超过 2 行。
字幕与旁白含义一致。
结尾 CTA 字幕必须包含：
立即尝试
用 AI 帮助你的求职
```

## 合规验收

```text
不展示真实邮箱、电话、学校账号、地址。
不伪造 offer、录取、面试邀请。
不承诺包就业或 100% 找到工作。
不使用未经授权的商标、音乐、人像。
不清晰展示未经授权的学校商标、校徽或真实学生身份。
```

## 最终交付验收

```text
最终文件路径：
hyperframes/exports/study_abroad_ai_job_search_12s_720p.mp4

视频可以正常播放。
无黑屏。
无花屏。
无明显卡顿。
有人声。
有字幕。
有画面变化。
有明确 CTA。
```
