# 01 Design

## 项目定位

本视频面向正在求职的海外留学生，核心目标是让观众意识到：AI 不只是聊天工具，也可以直接提高求职效率。

## 视频主题

```text
海外留学生怎么用 AI 提升求职效率
```

## 目标观众

```text
海外留学生
正在找实习的学生
正在找全职工作的应届生
想优化 LinkedIn、简历、Cover Letter 和面试准备的人
```

## 核心信息

```text
求职留学生可以用 AI 快速完成：
1. LinkedIn 主页优化
2. 英文简历修改
3. 岗位 JD 分析
4. Cover Letter 生成
5. 英文面试模拟
```

## 地点与背景设定

视频背景优先使用纽约市和哥伦比亚大学氛围，形成明确的海外留学生求职场景。

```text
城市背景：纽约市 skyline、Hudson River / Manhattan 远景、城市清晨或傍晚光线
学校背景：哥伦比亚大学校园、毕业生群像、图书馆/校园台阶/学习空间
人物设定：在纽约读书或求职的哥大学生/海外留学生
情绪基调：真实、努力、明亮、有目标感
```

## 视频规格

```text
时长：12 秒
比例：9:16 vertical
分辨率：720 x 1280
格式：MP4
平台：抖音 / 视频号 / 小红书
字幕：中文
旁白：中文女生
```

## 视觉方向

整体风格以“纽约市 + 哥大 + 留学生求职 + AI 工具界面”为主。用户提供的 LinkedIn 配图只作为其中一页素材，不作为整条视频唯一画面。

视觉关键词：

```text
纽约市天际线
哥伦比亚大学校园
哥大毕业生
浅蓝背景
LinkedIn 主页
留学生求职
AI 工具界面
简历优化
岗位匹配
大字标题
勾选清单
干净、明亮、实用教程感
```

需要补充的其他画面元素：

```text
纽约城市远景作为开场或转场背景
哥大校园或毕业生画面作为身份锚点
电脑上的 LinkedIn 主页
英文 Job Description
英文简历页面
AI 分析框或聊天窗口
Cover Letter 草稿
英文面试问题卡片
一句话生成视频的输入框
```

## 内容节奏

```text
0-3 秒：痛点钩子，指出留学生求职低效
3-8 秒：展示 AI 可以帮助完成的求职任务
8-12 秒：给出结果感，并引导观众立即尝试
```

## 结尾引导

结尾必须引导观众：

```text
立即尝试用 AI 帮助你的求职
```

该引导需要出现在字幕和画面 CTA 中。
